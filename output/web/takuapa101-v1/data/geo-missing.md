# สถานที่ที่ยังไม่มีพิกัด

| สถานที่ | ที่อยู่เท่าที่รู้ |
|---|---|
| ตักบาตรยามรุ่ง รับอรุณปีใหม่ | ไม่ทราบที่อยู่ |
| ประเพณีกินผัก (เจี๊ยะกิ๊วอ๋องฉ่าย) | ถนนศรีตะกั่วป่าและพื้นที่ชุมชนตลาดใหญ่ เมืองเก่าตะกั่วป่า |
| ประเพณีชักพระ | ไม่ทราบที่อยู่ |
| ลอยกระทง | บริเวณคลองตะกั่วป่า และจุดจัดงานตามที่องค์กรปกครองส่วนท้องถิ่นกำหนด |
| วัดปทุมธารา (วัดหน้าเมือง) | ถนนหน้าเมือง ชุมชนตลาดใหญ่ |
| ศูนย์อาหารลานโล่งตะกั่วป่า | ไม่ทราบที่อยู่ |
| โรงเจในสวน | ซอยโรงพระ ถนนราษฎร์บำรุง อำเภอตะกั่วป่า จังหวัดพังงา |
