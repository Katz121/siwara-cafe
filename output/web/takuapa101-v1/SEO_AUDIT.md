# ตะกั่วป่า 101 · แผน SEO และการตรวจแหล่งข้อมูล

## สิ่งที่ทำในต้นแบบนี้

- เพิ่มคลัสเตอร์เนื้อหา `/stories/` และบทความ 4 กลุ่ม: รู้จักเมือง, บ้านเก่าและสถาปัตยกรรม, สายน้ำและการค้า, ผู้คนและรสชาติ
- ทุกบทความมี canonical, breadcrumb, คำอธิบายหน้า, วันที่ปรับปรุง และลิงก์กลับไปยังสถานที่ในเว็บ
- แยกคำที่เป็นข้อเท็จจริงออกจากคำว่า “เชื่อมโยง”, “สันนิษฐาน” และ “ยังไม่มีข้อยุติ” พร้อม manifest ที่ `research/2026-09-07-history/audit.json`
- เพิ่ม `Article`/`BreadcrumbList` ในหน้าที่ระบบเดิมสร้าง และ sitemap ที่รวมหน้าเรื่องเล่า
- เมนู “กินและของฝาก” มีรายชื่อจากเอกสารเทศบาล 59 รายการ และรายการ first-party ของศิวรา คาเฟ่แยกให้เห็นชัดเจน รวม 60 รายการที่แสดงผล

## Search intent และ internal linking

กลุ่มคำค้นหลักควรเป็น “เมืองเก่าตะกั่วป่า”, “ประวัติตะกั่วป่า”, “สถาปัตยกรรมตะกั่วป่า”, “แม่น้ำตะกั่วป่า”, “ของกินตะกั่วป่า” และ “เที่ยวตะกั่วป่า” โดยให้บทความเป็นหน้าความรู้ แล้วเชื่อมไปยังแผนที่ สถานที่ และเส้นทางอ่านเมือง ไม่ทำหน้า doorway ที่มีเนื้อหาซ้ำกัน

ลิงก์ไป `https://siwaracafe.com/` ใช้ในบริบทที่อธิบายผู้จัดทำและรายการ first-party ของร้านเท่านั้น ใช้ anchor ที่เป็นภาษาคนและไม่วางลิงก์ซ้ำแบบ exact-match ทั้งเว็บ ห้ามซื้อลิงก์ แลกลิงก์ ทำ footer network หรือส่งเว็บเข้าไดเรกทอรีอัตโนมัติ หากมีลิงก์ที่ได้รับค่าตอบแทนในอนาคตให้ใช้ `rel="sponsored nofollow"`

## Gate ก่อนเปิด index จริง

1. เปลี่ยน `SITE_BASE_URL` เป็นโดเมนจริงและตรวจ canonical/sitemap หลัง deploy
2. เปลี่ยน `noindex,follow` เป็น `index,follow` เมื่อเจ้าของอนุมัติเนื้อหาและแหล่งข้อมูลแล้ว
3. ตรวจลิงก์หน่วยงานและเลขหน้า PDF ทุกครั้งที่มีการแก้บทความ
4. ตรวจข้อมูลร้าน เวลาเปิด และกิจกรรมกับผู้ให้บริการก่อนทำหน้าแนะนำเชิงปัจจุบัน
5. ส่ง sitemap ใน Search Console และตรวจ structured data หลังเปิดจริง
