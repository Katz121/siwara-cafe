## บริบทของเมือง (ใช้เป็นวัตถุดิบทางความคิด)
ตะกั่วป่าคือเมืองเหมืองแร่ดีบุกเก่า มีตึกแถวชิโน-โปรตุกีสสองชั้นเรียงยาวบนถนนสายวัฒนธรรม
มีศาลเจ้าจีนฮกเกี้ยน แม่น้ำตะกั่วป่าที่เคยเป็นเส้นทางข้ามคาบสมุทร สะพานเหล็กที่ทำจากเหล็กเรือขุดแร่
โรงเรียนจีนเต้าหมิงสีเหลืองสด ลายกระเบื้องเปอรานากันหน้าบ้าน และเจดีย์บนเขาพระบาท

## ข้อกำหนดทางเทคนิค (สำคัญมาก)
1. **เป็น "มาร์ก" อย่างเดียว ห้ามมีตัวอักษรไทยใน SVG** เพราะจะเอาไปวางคู่กับตัวหนังสือที่จัดใน HTML
   ใส่ตัวเลข 101 หรือ ๑๐๑ ได้ ถ้าวาดเป็น path หรือใช้ตัวเลขอารบิกล้วน
2. `viewBox="0 0 64 64"` ทุกไฟล์ · ไม่มี `width`/`height` แบบตายตัว
3. **ต้องอ่านออกที่ขนาด 32px และ 16px** เส้นบางเกินไปจะหายตอนย่อ · stroke อย่าต่ำกว่า 2.5 ที่ viewBox 64
4. ใช้สีจากชุดนี้เท่านั้น: เขียวเข้ม `#203f39` · ครีม `#f6f1e6` · สนิม `#a3492f` · ทอง `#e8a931` · กระดาษ `#fffdf7`
   ใช้ไม่เกิน 3 สีต่อโลโก้
5. ต้องดูดีทั้งบนพื้นครีมและพื้นเขียวเข้ม · ถ้าจำเป็นให้ทำ `currentColor` ในส่วนที่ต้องสลับ
6. ห้ามใช้ filter, mask, gradient ที่ซับซ้อน หรือฟอนต์ภายนอก · path ล้วนหรือรูปทรงพื้นฐาน
7. ห้ามลอกโลโก้ที่มีอยู่จริงของแบรนด์อื่น
8. ไฟล์ต้องเปิดในเบราว์เซอร์ได้จริง · ตรวจว่า XML ถูกต้อง ปิดแท็กครบ

## นอกจาก SVG
เขียนไฟล์ `brand/marks/{PREFIX}.json` เป็น array อธิบายแต่ละแบบ:
```
[{"file":"{PREFIX}-01.svg","name_th":"ชื่อแบบสั้น ๆ","idea_th":"แนวคิด 1-2 ประโยค ว่าดึงอะไรจากเมืองมา","strength_th":"จุดแข็ง","risk_th":"จุดอ่อนหรือข้อควรระวัง"}]
```

**เขียนไฟล์ลง path จริงในโฟลเดอร์นี้ ห้ามเขียนลง scratch directory**
**เขียนเป็น UTF-8 เท่านั้น** PowerShell ต้องใส่ -Encoding utf8 · Python ต้องใส่ encoding='utf-8'
เสร็จแล้วเปิดไฟล์อ่านกลับมายืนยันว่า SVG ถูกต้องและ JSON parse ผ่าน แล้วรายงาน
