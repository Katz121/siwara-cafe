## 2. ที่จะเพิ่ม · เรียงตามผลตอบแทน

### A · ข้อมูลจริง (กำลังรัน)
27 สถานที่/ประเพณี ยิง codex ค้นเว็บ ได้ต่อจุด: พิกัด lat/lng + ที่อยู่ + เวลาเปิด + ค่าเข้า + เบอร์/เพจ + วิธีเดินทาง 4 ทาง + ประวัติเชิงลึกมี status CONFIRMED/UNVERIFIED/DISPUTED ทุกข้อ + จุดเด่น 3-6 + ที่จอดรถ/ห้องน้ำ/รถเข็น + ที่ใกล้เคียง + รูปทางการ + คำค้น
กฎ: ทุก claim มี `source_url` · หาไม่เจอใส่ `null` เข้า `unknowns` ห้ามเดา
รอบสอง: 59 ร้านอาหาร/เครื่องดื่ม/ของฝาก (พิกัด เวลาเปิด เพจ เมนูเด่น)

### B · ไดนามิก 7 อย่าง
1. **แผนที่จริง MapLibre + OpenFreeMap** — ปักหมุด 27 จุดจากพิกัดจริง · คลิกหมุด→การ์ด · ฟิลเตอร์หมวด · ปุ่มนำทาง Google Maps · สลับ overlay แผนที่เทศบาลเดิมทับได้ · ไม่ต้องใช้ API key ไม่มีค่าใช้จ่าย
2. **ตะกร้าทริป / Trip planner** — กดเก็บที่อยากไป → เรียงเป็นเส้นทางเดินตามระยะจริง → ได้ลิงก์ Google Maps directions + พิมพ์เป็นแผ่นพกพา · แชร์ทริปได้ผ่าน URL = คนแชร์ = backlink ธรรมชาติ
3. **ปฏิทินเทศกาล 12 เดือน** — 7 ประเพณีวางบนปฏิทินจันทรคติ · นับถอยหลัง "อีก N วัน" · ปุ่มโหลด .ics เข้า Google Calendar
4. **ตอนนี้ควรไปไหน** — เวลาจริง + สภาพอากาศ (Open-Meteo ฟรี ไม่ต้อง key) → "บ่ายสองแดดจัด · แนะนำในร่ม" · โชว์ว่าที่ไหนเปิดอยู่
5. **โหมดเดินจริง** — บนมือถือขอ GPS → "คุณห่างบ้านขุนอินทร์ 120 ม." อ่านเรื่องตรงจุดที่ยืน
6. **Then & Now slider** — ภาพยุคเหมืองดีบุก vs วันนี้ เลื่อนเทียบ (เฉพาะภาพที่สิทธิ์ชัด)
7. **ค้นทั้งเว็บ Cmd+K** — 20 สถานที่ + 7 ประเพณี + 59 ร้าน ค้นภาษาไทยได้ทันที

### C · SEO
- โดเมนจริง + `index,follow` + canonical ถูก (ข้อ 1-2 คือ blocker ที่ต้องแก้ก่อนทุกอย่าง)
- schema เต็ม: `TouristAttraction`+`geo` / `Event` (เทศกาล) / `Restaurant` (59 ร้าน) / `FAQPage` / `ItemList` / `BreadcrumbList`
- หน้าสถานที่ยาว 800-1500 คำจากงานวิจัย + FAQ 4-6 ข้อต่อหน้า → เข้า featured snippet และ AI Overview
- หน้า pillar ยิงคำค้นใหญ่: `เที่ยวตะกั่วป่า` · `เมืองเก่าตะกั่วป่า` · `ตะกั่วป่า 1 วัน เที่ยวไหน` · `ที่เที่ยวพังงาไม่ใช่ทะเล` · `ชิโนโปรตุกีสตะกั่วป่า`
- **หน้าอังกฤษคู่ขนาน + hreflang** — `Takua Pa old town` คู่แข่งน้อยมาก แต่คนเขาหลักค้นทุกวัน
- OG image auto 1200×630 ต่อหน้าจาก illustration ที่มีอยู่ → แชร์แล้วสวย
- sitemap + robots + Search Console + IndexNow

### D · ลิงก์กลับ siwaracafe.com (ทำให้ถูกวิธี)
sitewide footer link แบบตอนนี้ Google ลดค่าอยู่แล้ว ทางที่ได้ผลจริงเรียงตามแรง:

1. **แรงที่สุด: วางเว็บเป็นโฟลเดอร์ของศิวราเลย** `siwaracafe.com/takuapa/` → authority ตกที่โดเมนศิวราตรง ๆ ไม่ต้องพึ่ง backlink สักลิงก์
2. ถ้าแยกโดเมน: ลิงก์ตามบริบทที่มีเหตุผลจริง เช่น หน้าถนนสายวัฒนธรรม → "แวะพักที่ศิวรา คาเฟ่ ห่าง N เมตร" พร้อมพิกัด · anchor หลากหลาย ไม่ exact-match ซ้ำ
3. หน้า **"พักเบรกระหว่างเดิน"** เป็นหน้าจริงที่ติดคำค้น `คาเฟ่ตะกั่วป่า` แล้วลิงก์ออก
4. ทุกเส้นทางใน trip planner มีจุดพักที่ศิวราเป็น stop หนึ่ง
5. `sameAs` ผูก schema สองเว็บเข้าหากัน + Google Business Profile ศิวรา
6. ห้าม: ซื้อลิงก์ แลกลิงก์ footer network ไดเรกทอรีอัตโนมัติ
