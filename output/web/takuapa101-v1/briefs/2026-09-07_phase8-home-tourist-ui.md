# Phase 8 · หน้าแรกและ UI สำหรับนักท่องเที่ยว

เจ้าของเว็บสั่ง: "หน้าแรกอยากให้มีสัดส่วนแสดงพวกกระทู้ ข่าวสารบ้าง เวลานักท่องเที่ยวเข้ามาจะได้เจอ · อยากสร้างเว็บให้เป็นมิตรกับนักท่องเที่ยว UI ต่างๆ ฟังก์ชันต่างๆ ใช้งานง่ายและครบ จบ"

## 8.1 · บล็อก "กระทู้และข่าวสารของเมือง" บนหน้าแรก
วางไว้ **สูงพอที่คนเลื่อนไม่นานก็เจอ** · เสนอให้อยู่หลังแถบ "เริ่มที่นี่" และก่อนกริดสถานที่

โครงสร้าง 2 คอลัมน์บนเดสก์ท็อป · เรียงลงบนมือถือ
- **ซ้าย · เรื่องเล่าของเมือง** การ์ด 5 บทความจาก `data/stories/*.json` (ภาพ hero ถ้ามี · หัวเรื่อง · dek · เวลาอ่านกี่นาที) · การ์ดใบแรกใหญ่กว่าใบอื่น
- **ขวา · ความเคลื่อนไหวล่าสุด** รวม `news[]` จากทุก record ใน `data/places-enriched.json` (34 ชิ้น) เรียงวันที่ใหม่ไปเก่า แสดง 6-8 ชิ้น · แต่ละชิ้น: วันที่ · ชื่อข่าว · สำนักข่าว · ชื่อสถานที่ที่เกี่ยวข้อง (ลิงก์เข้าหน้าสถานที่) · ลิงก์ข่าวต้นทาง `rel="noopener"`
- ปุ่มท้ายบล็อก: "อ่านเรื่องเล่าทั้งหมด" และ "ดูความเคลื่อนไหวทั้งหมด" (สร้างหน้า `/news/` รวมข่าวทั้ง 34 ชิ้น พร้อมฟิลเตอร์ตามสถานที่)

## 8.2 · แถบ "เริ่มที่นี่" ใต้ hero
4 ปุ่มใหญ่ ไอคอนเส้น ไม่ใช้ emoji · แตะง่ายบนมือถือ (สูงอย่างน้อย 56px)
1. **กางแผนที่** → `/map/`
2. **เที่ยวไหนดี** → `/places/`
3. **กินอะไรดี** → `/eat/`
4. **จัดทริปของฉัน** → `/trip/` พร้อม badge จำนวนที่เลือกไว้

## 8.3 · หัวเว็บและแถบล่างบนมือถือ
- หัวเว็บ: เพิ่มปุ่มค้นหา และปุ่มทริปพร้อม badge จำนวน (`[data-trip-count]`)
- **แถบล่างติดจอเฉพาะจอ < 900px**: หน้าแรก · แผนที่ · ค้นหา · ทริป · เมนู · ปุ่มที่กำลังอยู่ให้ `aria-current="page"`
- เมนูหลักบนมือถือปัจจุบันยาวเกิน ให้ยุบเป็นปุ่ม "เมนู" เปิด drawer

## 8.4 · ค้นหาทั้งเว็บ
- กด `/` หรือ `Ctrl+K` หรือปุ่มแว่นขยาย → เปิดกล่องค้นหากลางจอ
- ค้นได้: 20 สถานที่ + 7 ประเพณี + 59 ร้าน + 5 บทความ · ค้นทั้งชื่อไทย ชื่ออังกฤษ และ `seo.keywords_th`
- สร้าง `site/assets/search-index.json` ตอน build · ค้นแบบ substring ไม่ต้องใช้ไลบรารี
- ผลลัพธ์กดขึ้น/ลง Enter เปิดได้ · Escape ปิด · โฟกัสกลับที่ปุ่มเดิม

## 8.5 · "ตอนนี้ควรไปไหน"
การ์ดเล็กบนหน้าแรก
- เวลาไทยจริงจากเครื่องผู้ใช้
- อากาศจาก Open-Meteo `https://api.open-meteo.com/v1/forecast?latitude=8.86&longitude=98.35&current=temperature_2m,precipitation,weather_code&timezone=Asia%2FBangkok` (ฟรี ไม่ต้อง key)
- ตรรกะ: ฝนตกหรือแดดจัดช่วง 11:00-15:00 → แนะนำที่ในร่ม (พิพิธภัณฑ์ · ศาลเจ้า · ตลาด) · ช่วงเย็น → แนะนำริมน้ำและถนนสายวัฒนธรรม
- แสดงด้วยว่าที่ไหน "เปิดอยู่ตอนนี้" เฉพาะที่ `visit.opening_hours_status == "CONFIRMED"` เท่านั้น
- ถ้า API ล้มเหลว ให้ซ่อนการ์ดเงียบ ๆ ห้ามขึ้น error

## 8.6 · ให้ใช้ง่ายจริง
- ทุกหน้าสถานที่และทุก popup ในแผนที่ต้องมีปุ่ม "เพิ่มลงทริป" (`data-trip-add="<id>"`)
- ปุ่มนำทางต้องเปิด Google Maps ได้ทันทีทุกที่ที่มีพิกัด
- ปุ่มและลิงก์ที่แตะได้ต้องสูงอย่างน้อย 44px บนมือถือ
- ข้อความที่บอกว่า "ยังไม่ยืนยัน" ต้องอ่านออกแต่ไม่แย่งความสนใจ
- แสดงเวลาอ่านโดยประมาณบนบทความทุกบท

## กฎรวม
- vanilla เท่านั้น · ไม่เพิ่ม dependency · MapLibre เป็น CDN ตัวเดียวที่ใช้ได้
- ลิงก์ภายในทุกอันต้องมี BASE_PATH `/takuapa`
- ใช้ได้ที่ 390px · ไม่พังเมื่อปิด JS (บล็อกข่าวและเรื่องเล่าต้อง render เป็น HTML จริงตอน build ไม่ใช่ JS เติม)
- ภาษาไทยทั้งหมด · ใช้ `·` แทน em/en-dash · ห้าม emoji
- **เขียนไฟล์เป็น UTF-8 เท่านั้น** ไม่งั้นภาษาไทยจะกลายเป็นเครื่องหมายคำถาม
- ธีมเดิม ครีม #f6f1e6 เขียวเข้ม #203f39 · Noto Serif Thai + IBM Plex Sans Thai Looped
