## PHASE 2 · SEO plumbing (codex luna)
- `SITE_BASE_URL = "https://siwaracafe.com/takuapa"` · canonical/sitemap/OG ทุกหน้าใช้ค่านี้
- `robots` เป็น `index,follow` ทุกหน้า ยกเว้นหน้าที่ยังไม่พร้อม
- JSON-LD ต่อชนิดหน้า:
  - สถานที่ → `TouristAttraction` + `geo{latitude,longitude}` + `address{PostalAddress}` + `openingHours` (เฉพาะที่ CONFIRMED) + `image` + `isPartOf`
  - ประเพณี → `Event` + `startDate` ถ้ารู้ · ไม่รู้ให้ใช้ `eventSchedule` แบบ repeat
  - ร้าน 59 ร้าน → `Restaurant` / `CafeOrCoffeeShop` / `Store`
  - หน้า index → `ItemList` · ทุกหน้า `BreadcrumbList` · หน้าแรก `WebSite` + `SearchAction`
  - **ห้ามใส่ field ที่ไม่มีข้อมูลจริง** (เช่น `openingHours` ที่เดาเอง) → rich result จะโดนตี
- FAQ 4-6 ข้อต่อหน้าสถานที่ จากคำถามที่ตอบได้จากข้อมูลจริงเท่านั้น + `FAQPage` schema
- OG image auto 1200×630 ต่อหน้า: illustration เดิม + ชื่อสถานที่ + แถบ "ตะกั่วป่า 101" → `site/assets/og/{id}.png`
- `sitemap.xml` ครบทุก URL + `lastmod` · `robots.txt` ชี้ sitemap · ping IndexNow

## PHASE 3 · หน้าสถานที่แบบเต็ม (codex astra — งานหนัก)
โครงหน้าใหม่ เรียงจากบนลงล่าง:
1. hero: ภาพจริง (ถ้ามี) ไม่มีก็ illustration · ชื่อไทย/อังกฤษ · หมวด · badge "ข้อมูลยืนยันแล้ว N ข้อ"
2. **การ์ดข้อมูลใช้จริง** (sticky บนเดสก์ท็อป): พิกัด · ปุ่มนำทาง Google Maps · เวลาเปิด · ค่าเข้า · ที่จอดรถ · ห้องน้ำ · รถเข็น · เบอร์/เพจ — ช่องไหนไม่รู้เขียนว่า "ยังไม่ยืนยัน" ตรง ๆ ห้ามเว้นว่างเงียบ ๆ
3. **ไทม์ไลน์ 3 ยุค** — "ตอนนั้น / ก่อนหน้า / ตอนนี้" แต่ละยุค 2-4 ย่อหน้า + ภาพประกอบยุคนั้น + แหล่งอ้างอิงท้ายยุค · แสดงเป็น 3 การ์ดแนวตั้งบนมือถือ / สลับซ้ายขวาบนเดสก์ท็อป
4. **เส้นเวลาแบบจุด** — `timeline[]` เรียงปี ค.ศ./พ.ศ. เลื่อนแนวนอนได้ · badge สี: เขียว CONFIRMED · เหลือง UNVERIFIED · ส้ม DISPUTED
5. แกลเลอรีภาพ (lightbox) แยกแท็บ "ภาพเก่า" / "ภาพวันนี้" · ทุกใบมี credit ใต้ภาพ
6. จุดเด่นที่ควรดู 3-6 ข้อ
7. **ข่าวและความเคลื่อนไหว** — `news[]` 5 ปีล่าสุด เรียงใหม่→เก่า มีวันที่ สำนักข่าว ลิงก์
8. รู้หรือไม่ — `did_you_know[]`
9. วิธีเดินทาง 4 ทาง (ตัวเมือง/ภูเก็ต/เขาหลัก/สนามบิน)
10. ที่ใกล้เคียง + ปุ่ม "เพิ่มลงทริป"
11. FAQ
12. **ที่มาของข้อมูล** — ลิสต์ทุกแหล่งพร้อมวันที่เข้าถึง + กล่อง "ข้อมูลที่ยังหาไม่เจอ" จาก `unknowns` (ความซื่อสัตย์นี้คือจุดต่างจากบล็อกท่องเที่ยวทั่วไป และ Google ให้ค่า)

กฎแสดงผล: ข้อมูล UNVERIFIED ต้องมีป้ายกำกับที่ผู้อ่านเห็น ห้ามปนกับ CONFIRMED เนียน ๆ

## PHASE 4 · แผนที่จริง (codex astra)
- MapLibre GL JS + สไตล์ OpenFreeMap `liberty` (ฟรี ไม่ต้อง key) · โหลดจาก CDN
- ปักหมุด 20 จุดที่มีพิกัด · 3 จุดที่ยังไม่มีพิกัด (`food-center`, `rong-jae`, `wat-pathum`) แสดงในลิสต์ข้างแผนที่ พร้อมหมายเหตุ "รอปักหมุด" **ห้ามเดาพิกัด**
- หมุดสีตามหมวด · คลิก → การ์ดข้อมูลย่อ + ปุ่ม "เปิดหน้าเต็ม" + "นำทาง" + "เพิ่มลงทริป"
- ปุ่มสลับ layer: แผนที่จริง / ภาพแผนที่เทศบาลเดิมซ้อนทับ (georeference คร่าว ๆ ปรับ opacity ได้)
- fallback: ไม่มี JS ต้องเห็นภาพแผนที่เทศบาลเดิม + รายชื่อ 27 จุดพร้อมลิงก์ (แบบเดิมที่ทำไว้แล้ว ห้ามทำถอยหลัง)

## PHASE 5 · ตะกร้าทริป (codex luna)
- ปุ่ม "เพิ่มลงทริป" ทุกที่ที่มีสถานที่ · เก็บใน localStorage
- หน้า `/trip/`: รายการที่เลือก ลากสลับลำดับได้ · เรียงอัตโนมัติตามระยะทางจริง (haversine) · รวมเวลาโดยประมาณจาก `duration_minutes`
- ปุ่ม: เปิดใน Google Maps (directions หลายจุด) · คัดลอกลิงก์ทริป (encode ลง query string) · พิมพ์ (print stylesheet A4)
- ทุกทริปเสนอ "จุดพักระหว่างทาง" = ศิวรา คาเฟ่ พร้อมพิกัดจริง (นี่คือ contextual link ที่ถูกกติกา)

## PHASE 7 · ลิงก์กลับศิวรา (codex luna)
เว็บอยู่ subfolder ของ siwaracafe.com แล้ว authority ตกที่โดเมนเองอยู่แล้ว ลิงก์ภายในจึงทำเพื่อ "พาคนเดินไปหาร้าน" ไม่ใช่เพื่อ SEO:
- หน้า `/takuapa/rest/` "พักเบรกระหว่างเดินเมืองเก่า" — เนื้อหาจริงเรื่องจุดพัก ยิงคำค้น `คาเฟ่ตะกั่วป่า` `ที่นั่งพักเมืองเก่าตะกั่วป่า`
- ลิงก์ตามบริบทในหน้าที่เกี่ยวข้องจริง (ถนนสายวัฒนธรรม · ตลาดริมน้ำ · ศูนย์อาหาร) พร้อมระยะทางจริงจากพิกัด
- ตะกร้าทริปเสนอศิวราเป็นจุดพัก
- `sameAs` ผูก schema ระหว่าง `/takuapa/` กับหน้าร้าน
- anchor ต้องหลากหลาย ห้าม exact-match ซ้ำทุกหน้า · เอาลิงก์ footer sitewide เดิมออก เหลือลิงก์ "จัดทำโดย" 1 จุดในหน้า about
