## 0. จุดยืนของเว็บ

Takuapa101 คือ **คู่มือเมืองเก่าตะกั่วป่าที่ใช้ได้จริง** ไม่ใช่หน้าโปรโมตคาเฟ่ที่แปะข้อมูลเมือง คุณค่าที่คนอื่นลอกไม่ได้มีสามอย่าง

1. ภาพประกอบรายสถานที่ 20 ชิ้นที่ผลิตเอง เป็นชุดเดียวกันทั้งเว็บ
2. ผังถนนย่านเก่าที่ trace จากแผนที่เทศบาล ซึ่งไม่มีบนเว็บท่องเที่ยวทั่วไป
3. ความโปร่งใสของแหล่งข้อมูล ทุกข้อมูลบอกได้ว่ามาจากไหนและอะไรยังไม่ยืนยัน

หน้าตาต้องเป็น **สิ่งพิมพ์เมืองเก่า** ไม่ใช่ dashboard การ์ดใหญ่ ไม่ใช่ template ททท.

## 1. หน้าแรก · องค์ประกอบและหัวข้อจริง

เรียงจากบนลงล่าง หัวข้อคือข้อความที่ให้ใช้ตรงตัว

**A. Masthead** (เต็มความกว้าง พื้น `--paper` มีเส้น linework ถนนจาง 6% เป็นพื้นหลัง ไม่ใช่ภาพถ่าย)
- ตราคำ `ตะกั่วป่า 101`
- บรรทัดรอง `คู่มือเมืองเก่าตะกั่วป่า · วัด ศาลเจ้า ตึกเก่า และย่านตลาดริมน้ำ`
- ประโยคนำ 2 บรรทัด บอกว่าเว็บนี้รวบรวมอะไร และข้อมูลมาจากแผ่นพับเทศบาลเมืองตะกั่วป่า
- ปุ่มข้อความสองอัน `เปิดแผนที่ย่านเก่า` · `ดูสถานที่ทั้ง 20 แห่ง` (เป็น text link มีเส้นใต้ ไม่ใช่ปุ่มกลมสีจัด)

**B. `เริ่มจากตรงนี้`** — สามเส้นทางเดิน ไม่ใช่การ์ด แต่เป็นรายการแบบสารบัญ มีเลขลำดับ Cormorant ตัวใหญ่ ชื่อเส้นทาง และรายชื่อจุดแวะคั่นด้วย `·`
- `เส้นวัดและเจดีย์` · `เส้นศาลเจ้าและโรงเจ` · `เส้นตึกเก่าและตลาดริมน้ำ`

**C. `แผนที่ย่านเก่า`** — ผัง SVG ย่อ กว้างเต็ม container ความสูงจำกัด พร้อมลิงก์ `เปิดแผนที่เต็มและรายชื่อจุด`

**D. `สถานที่ 20 แห่ง`** — ดัชนีแบบ editorial แบ่งเป็นหมวดย่อยพร้อมหัวข้อเล็ก
- `วัด` (6) · `ศาลเจ้าและโรงเจ` (4) · `ตึกเก่าและร่องรอยเมือง` (4) · `สวนและพื้นที่สาธารณะ` (2) · `ตลาด ถนน และของกิน` (3) · `พิพิธภัณฑ์` (1)
- แต่ละรายการ = ภาพ 4:5 กว้าง 180-220px + ชื่อไทย + kicker จาก `card-copy.json` หนึ่งบรรทัด ไม่มีกล่องเงา ใช้เส้นคั่น `--rule` แทน

**E. `ประเพณีตลอดปี`** — ไทม์ไลน์แนวนอนบนจอใหญ่ / แนวตั้งบนมือถือ 7 รายการ ใช้ `source_period` เท่านั้น รายการที่ไม่มีช่วงเวลาระบุว่า `เอกสารไม่ระบุช่วงเวลา`

**F. `กินและซื้อของฝากในย่าน`** — บล็อกเดียว บอกว่ามีรายชื่อ 59 ร้านจากแผ่นพับ แยก 3 หมวด ลิงก์ไป `/eat/` **ห้ามโชว์ทั้ง 59 ชื่อบนหน้าแรก**

**G. `ข้อมูลนี้มาจากไหน`** — 3-4 บรรทัด บอกแหล่ง วันที่สกัด และสิ่งที่ยังไม่ยืนยัน ลิงก์ไป `/about/`

**H. Footer** — `จัดทำโดยบ้านศิวรา ตะกั่วป่า` + ลิงก์ siwaracafe.com หนึ่งจุด + ลิงก์แผ่นพับต้นทาง

### Navigation (sticky บาง สูง 56px พื้นกระดาษ เส้นล่าง 1px)
`สถานที่` · `แผนที่` · `ประเพณี` · `กินและของฝาก` · `เส้นทางเดิน` · `เกี่ยวกับ`

## 2. Information architecture และผัง URL

| URL | เนื้อหา | จำนวนหน้า |
|---|---|---|
| `/` | หน้าแรก | 1 |
| `/places/` | ดัชนีสถานที่ แบ่ง 6 หมวด | 1 |
| `/places/{id}/` | หน้าสถานที่ | 20 |
| `/traditions/` | ประเพณีตลอดปี | 1 |
| `/traditions/{id}/` | หน้าประเพณี | 7 |
| `/eat/` | ไดเรกทอรี 59 ร้าน 3 หมวด | 1 |
| `/routes/` | เส้นทางเดิน 3 เส้น | 1 |
| `/map/` | แผนที่เต็ม + รายชื่อจุด | 1 |
| `/about/` | ที่มา ความสัมพันธ์กับศิวรา ข้อจำกัด | 1 |

รวม 34 หน้า indexable · id ใช้ค่าจาก `library.json` ตรงตัว (`wat-boromthat`, `pun-thao`, ...) · ทุก URL ปิดท้าย `/` และ build เป็น `index.html`

**59 ร้านไม่มีหน้าของตัวเอง** อยู่บน `/eat/` เป็น anchor `#restaurant-01` เพราะมีแค่ชื่อ การแตกเป็น 59 หน้าคือ thin content ที่ทำร้ายทั้งเว็บ เมื่อไหร่มีข้อมูลจริง (เวลาเปิด เมนู ภาพ) ค่อยเลื่อนขึ้นเป็นหน้าเดี่ยว

### เทมเพลตหน้าสถานที่ (`/places/{id}/`)
1. Breadcrumb `หน้าแรก · สถานที่ · {ชื่อ}`
2. ชื่อไทย (h1) + ชื่ออังกฤษเป็น Cormorant ใต้ชื่อ
3. ภาพประกอบเต็มความกว้าง content (max 720px) `loading=lazy` มี width/height กัน CLS
4. Kicker จาก `card-copy.json` เป็น lead paragraph
5. `เรื่องของที่นี่` — body จาก card-copy + `facts_paraphrased`
6. `รายละเอียดจากเอกสาร` — definition list จาก `source_details` เช่น `สร้างเมื่อ พ.ศ. 2436` ข้อความ superlative ต้องเขียนแบบอ้างอิงเสมอ เช่น `เอกสารเทศบาลระบุว่าเป็นอุโบสถขนาดเล็กที่สุดในไทย ยังไม่ได้ตรวจเทียบกับแหล่งอื่น`
7. `อยู่ตรงไหนในย่าน` — ผัง SVG ย่อเฉพาะจุดนี้ + ชื่อถนนที่ใกล้ที่สุดจากแผนที่ต้นทาง ถ้าไม่ปรากฏบนแผนที่ให้ใส่ `ไม่ปรากฏตำแหน่งในแผนที่ต้นทาง`
8. `เกี่ยวข้องกัน` — ลิงก์ไปสถานที่หมวดเดียวกัน 2-3 แห่ง และประเพณีที่ผูกกัน
9. `ที่มาของข้อมูล` — แหล่ง วันที่สกัด และประโยคระบุว่าอะไรยังไม่ยืนยัน

### ลิงก์ภายในที่มีความหมายจริง (ไม่ใช่ลิงก์สุ่ม)
- `narai-ceremony` ↔ `phra-narai`
- `vegetarian` ↔ `guan-yu` `pun-thao` `kue-chai` `rong-jae`
- `relic-procession` ↔ `wat-boromthat`
- `chak-phra` ↔ วัดทั้ง 6
- `loy-krathong` ↔ `riverwalk`
- `ruler-ceremony` ↔ `governor-wall`
- `culture-street` ↔ `tao-ming` `khun-in` `iron-bridge` `food-center`

ให้ Codex เก็บ mapping นี้เป็น `data/links.json` แล้ว build ใช้ ห้าม hardcode ใน template

## 3. Design system

### สี (โหมดเดียว สว่าง คอมมิตชัดเจน กำหนดสีพื้นหลัง body ตรงๆ)
```
--paper      #FBF6EA   พื้นหน้า
--paper-deep #F3E8CE   บล็อกเน้น / แถบ
--ink        #2B4535   ตัวหนังสือหลัก
--ink-soft   #5C6F62   ตัวหนังสือรอง
--brick      #96613E   ลิงก์ เลข accent
--rule       #C9B48A   เส้นคั่น 1px
--pin        #B4472F   หมุดแผนที่ active
```
ห้ามใช้เงาแบบ material ทุกการแบ่งพื้นที่ทำด้วยเส้น 1px และช่องว่าง

### ตัวอักษร (self-host ทั้งหมด แปลง ttf เป็น woff2 subset ก่อน)
- หัวข้อไทย `Noto Serif Thai` 600 · h1 clamp(32px, 5vw, 46px) · h2 26px · line-height 1.35
- เนื้อไทย `IBM Plex Sans Thai Looped` 400 · 17px มือถือ 18px เดสก์ท็อป · line-height 1.78
- อังกฤษ ตัวเลข kicker `Cormorant Garamond` 600 · ใช้กับ ชื่อ EN เลขลำดับ เลขปี เท่านั้น
- ความกว้างบรรทัดสูงสุด 34em (ไทยยาวกว่า 68ch จะอ่านยาก) · ห้าม letter-spacing ติดลบกับไทย
- `font-display: swap` + preload สองไฟล์แรก

### ระยะและกริด
- สเกล 4 8 12 16 24 32 48 64 96
- container 1120px · content column 720px · gutter 20px มือถือ / 32px เดสก์ท็อป
- ดัชนีสถานที่ 1 คอลัมน์ (<640) / 2 (<1024) / 3 (≥1024) ใช้ CSS grid ไม่ใช้ framework

### เส้นแผนที่ (linework)
- stroke `--rule` ถนนหลัก 2.5px ซอย 1.5px แม่น้ำ 6px สีฟ้าอมเขียวจาง `#A8C4BE`
- ชื่อถนน Cormorant 12px `--ink-soft` วางตามแนวถนนด้วย `textPath`
- พื้นหลัง masthead ใช้ path เดียวกัน opacity 0.06 หมุนเล็กน้อย ไม่มีตัวอักษร
- **ภาพประกอบกับผังเส้นเป็นคนละเลเยอร์เสมอ** ห้ามฝังภาพลงใน SVG แผนที่

### มือถือ
- nav ยุบเป็นแถวเลื่อนแนวนอน ไม่ทำ hamburger overlay
- แผนที่ default แสดง **รายชื่อจุด** ก่อน มีปุ่ม `ดูเป็นผังแผนที่` เพื่อเปิดผังในกล่อง pinch-zoom
- ภาพในดัชนีวางซ้าย 96px ข้อความขวา ไม่ใช่การ์ดเต็มจอ

## 4. แผนเลเยอร์แผนที่ · ข้อจำกัดและ fallback

ต้นทาง `site/assets/municipal-map.png` เป็นผังภาพประกอบ ไม่ใช่แผนที่สำรวจ

**เลเยอร์ 1 · ถนนและแม่น้ำ (ทำมือ)**
Codex trace polyline จากภาพเป็น viewBox `0 0 1000 1400` ตามสัดส่วนภาพจริง เก็บใน `site/map/streets.svg` ถนนที่ต้องมีชื่อกำกับ
`ถนนเพชรเกษม` `ถนนเสนารัฐ` `ถนนศรีมนตรี` `ถนนศรีเมือง` `ถนนบรมธาตุ` `ถนนมนตรี 2` `ถนนศรีตะกั่วป่า` `ถนนอุดมธารา` `ถนนเสนานุชิต` `ถนนหน้าเมือง` `ถนนเกี่ยวข้าว` `ซอยศรีมนตรี` `ซอยหิรัณย์` `ซอยรวงผึ้ง` และ `แม่น้ำตะกั่วป่า`

**เลเยอร์ 2 · หมุดสถานที่** `data/map-points.json` โครง `{id, x, y, confidence}` โดย
- `confidence: "from_source_map"` = ปรากฏบนแผนที่เทศบาลชัดเจน (คาดว่าราว 14-16 จาก 20 แห่ง ให้ Codex นับจริงแล้วรายงาน)
- `confidence: "not_on_source_map"` = ไม่มีหมุด ไม่ต้องเดาตำแหน่ง ให้อยู่ใน `รายชื่อจุดที่ไม่ปรากฏบนแผนที่ต้นทาง` ใต้ผัง

**เลเยอร์ 3 · หมายเลขร้าน (toggle ปิดเป็นค่าเริ่มต้น)** แผนที่ต้นทางมีหมุดตัวเลข 3 สี ซึ่งตรงกับ `source_list_number` ของ 59 ร้าน map สีเป็นหมวด ให้ Codex ตรวจ mapping ทีละสีจากภาพก่อนใช้ ถ้าจับคู่ไม่ครบให้ทำเฉพาะที่มั่นใจแล้วบันทึกที่เหลือไว้ใน `data/map-gaps.md`

**interaction**
- hover/tap หมุด → tooltip ชื่อไทย + ลิงก์หน้าสถานที่ · หมุดเป็น `<a>` จริง มี `focus-visible` ring และ tab ตามลำดับที่อ่านรู้เรื่อง
- ไม่มี pan/zoom library ภายนอก ใช้ CSS `overflow:auto` + `touch-action` พอ
- ทุกหมุดมีคู่ในตารางใต้แผนที่ ตารางคือ fallback ที่ใช้งานได้เต็มโดยไม่ต้องมี JS

**คำกำกับใต้แผนที่ (ใช้ข้อความนี้)**
`ผังนี้อ้างอิงตำแหน่งจากแผนที่ประชาสัมพันธ์ของเทศบาลเมืองตะกั่วป่า ระยะและสัดส่วนไม่ตรงตามพื้นที่จริง`

**ห้าม** ใส่พิกัด GPS ระยะทาง เวลาเดิน หรือหมุดบ้านศิวราลงบนแผนที่

## 5. SEO · เรียงตามลำดับที่ต้องทำ

**ต้องมีก่อนเปิด**
1. `SITE_BASE_URL` เป็น env ของ build script ค่า default `http://localhost:8080` ทุก canonical og sitemap อ่านจากตัวนี้ ห้าม hardcode โดเมน
2. title และ meta description **เขียนรายหน้า** จาก kicker + ชื่อ ไม่ใช้สูตรเดียวซ้ำ 34 หน้า ยาว 55-62 และ 140-158 ตัวอักษร
3. `sitemap.xml` และ `robots.txt` generate จาก build · หน้า prototype ตั้ง `noindex` จนกว่าจะยืนยันโดเมน
4. JSON-LD ต่อหน้า
   - ทุกหน้า `WebSite` + `BreadcrumbList`
   - `/places/{id}/` ใช้ `Place` เฉพาะ `name` `description` `image` `containedInPlace: ตะกั่วป่า จังหวัดพังงา` **ไม่ใส่** `address` `geo` `openingHours` `aggregateRating`
   - `/routes/` และ `/traditions/{id}/` ใช้ `Article` มี `author` `datePublished` จริง
   - **ไม่ใช้ `Event` schema** เพราะไม่มีวันที่ยืนยัน
5. ภาพทุกใบ `alt` บรรยายจริง (เช่น `ภาพประกอบเจดีย์สีขาววัดบรมธาตุคีรีเขต`) + width/height + `loading=lazy` ยกเว้นภาพแรกในหน้า
6. hreflang ไม่ต้อง เว็บภาษาเดียว · `<html lang="th">`

**ทำหลังเปิด**
7. หน้า `/routes/` แตกเป็น 3 หน้าเมื่อเนื้อหาแต่ละเส้นยาวพอ (300+ คำจริง)
8. เก็บ Search Console แล้วดูว่า query ไหนเข้ามา ค่อยเขียนหน้าใหม่ตามนั้น

**ห้าม** อ้างว่า schema รับประกัน rich result หรืออันดับ · ห้ามสร้าง rating รีวิว หรือคำพูดสัมภาษณ์

## 6. กลยุทธ์ลิงก์ไปศิวรา

ลิงก์ทั้งเว็บ **สามจุดเท่านั้น** anchor ต่างกันทุกจุด

1. `/about/` ย่อหน้าเปิดเผยตรงๆ ว่า เว็บนี้จัดทำและออกค่าใช้จ่ายโดยบ้านศิวรา ร้านในตะกั่วป่า เนื้อหาไม่ได้รับค่าตอบแทนจากร้านใดในไดเรกทอรี anchor = `บ้านศิวรา`
2. `/routes/` เส้นที่ผ่านย่านนั้น หนึ่งบรรทัดจบ anchor พรรณนา เช่น `แวะพักระหว่างทางที่บ้านศิวรา`
3. footer ทุกหน้า `จัดทำโดยบ้านศิวรา`

เป็นลิงก์เจ้าของเดียวกันและไม่มีเงินแลกเปลี่ยน จึงใช้ลิงก์ปกติได้ แต่ต้องเปิดเผยความสัมพันธ์ตามข้อ 1 ถ้าอนาคตมีร้านจ่ายเงินลงเนื้อหา ลิงก์นั้นต้อง `rel="sponsored"` และมีป้ายกำกับที่ผู้อ่านเห็น

## 8. กฎที่ห้ามฝ่าฝืน (Codex ต้องเช็คก่อนส่งงาน)

1. `pun-thao` = ศาลาเสาขาว · `rong-jae` = ซุ้มประตูจีนสีแดง ห้ามสลับกลับ
