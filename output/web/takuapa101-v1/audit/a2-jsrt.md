# รายงานตรวจ JavaScript ตอนรันจริง · a2

วันที่ตรวจ · 8 กันยายน 2569  
วิธีตรวจ · เสิร์ฟด้วย `python -m http.server 8799 --directory site` และเปิดผ่าน Playwright ที่ `http://127.0.0.1:8799`  
ขอบเขต · ทุก `index.html` ใน `site/` ที่ไม่อยู่ใต้ `/en/` รวม 44 หน้า

## 1 · Console error และ warning

ตรวจแล้วไม่พบปัญหาใน 43 หน้า · หน้า `/map/` พบ warning 1 รายการ:

· **ข้อสังเกต · `/map/`** · `warning: [.WebGL-... ] GL Driver Message (OpenGL, Performance, GL_CLOSE_PATH_NV, High): GPU stall due to ReadPixels` · เป็น warning จาก WebGL/GPU ระหว่างแผนที่ทำงาน ไม่พบ JavaScript error ร่วมในหน้านี้

หน้าอื่น ๆ ที่ตรวจ · `/`, `/about/`, `/eat/`, `/leaflet/`, `/news/`, `/places/`, หน้ารายละเอียดสถานที่ 20 หน้า, `/rest/`, `/routes/`, `/stories/`, หน้ารายละเอียดเรื่องเล่า 5 หน้า, `/traditions/`, หน้ารายละเอียดประเพณี 7 หน้า และ `/trip/` · ตรวจแล้วไม่พบปัญหา

## 2 · Request ที่ตอบ 404 หรือ 5xx

ตรวจแล้วไม่พบปัญหา · ทั้ง 44 หน้าไม่พบ response status 404 หรือ 5xx ระหว่างโหลดหน้า

## 3 · ทดสอบฟังก์ชันและค่าข้ามหน้า

· **ค้นหา Ctrl+K · ผ่าน** · เปิด `/` แล้วกด `Control+K` พบช่องค้นหาที่มองเห็นได้ (`input[type=search]:visible`) · หลักฐาน · `/`, การทดสอบ Playwright

· **ตัวกรอง `/places/` · ผ่าน** · จำนวนการ์ดที่มองเห็นก่อนกรอง 20 และหลังคลิก `[data-filter="temple"]` เหลือ 6 · หลักฐาน · `/places/`, `[data-place-card]:visible` = `20 → 6`

· **ตัวกรอง `/eat/` · ตรวจไม่ได้เพราะอะไร** · หน้า `/eat/` ไม่พบ element `[data-filter]` จาก DOM ที่โหลดจริง (`0` รายการ) จึงไม่มีตัวควบคุมตาม selector นี้ให้ทดสอบอย่างมีหลักฐาน · ไม่สรุปว่าเป็นปัญหา JavaScript

· **ปุ่มธีม · ผ่าน** · คลิก `[data-theme-toggle]` แล้ว `html[data-theme]` เปลี่ยนเป็น `dark` และเมื่อไป `/about/` ค่ายังคงเป็น `dark` · หลักฐาน · `/` → `/about/`, Playwright

· **ตะกร้าทริป · ตรวจได้บางส่วน** · หน้า `/trip/` โหลดและแสดงข้อความ `ทริปของคุณยังว่างอยู่` · แต่การทดสอบเพิ่มรายการจากหน้ารายละเอียด `/places/wat-boromthat/` ค้างระหว่างการนำทาง/รอหน้าในรอบตรวจ จึงตรวจยืนยันการเพิ่มรายการและการคงค่าข้ามหน้าไม่ได้ · ไม่มีการรายงานว่าเป็นบั๊กเพราะยังไม่มีหลักฐานผลลัพธ์ที่เชื่อถือได้

## 4 · ตรวจ event listener ผูกซ้ำ

ตรวจจาก DOM ที่โหลดจริงทุกหน้าและรายการ script ที่หน้าโหลด:

· ทุกหน้าที่ตรวจมี `/assets/trip.js` 1 ครั้ง · `/trip/` มี `/assets/trip.js` 1 ครั้งและ `/assets/trip-page.js` 1 ครั้ง
· ตรวจไม่พบกรณี `trip.js` ถูกโหลดซ้ำสองรอบในหน้าใดจากรายการ `<script src>` · **ตรวจแล้วไม่พบปัญหา**
· หลักฐานเพิ่มเติม · `rg` พบจุดผูกปุ่มใน `site/assets/trip.js` และ attribute `[data-trip-add]` ในหน้ารายละเอียดสถานที่ แต่การพิสูจน์จำนวน listener ที่ผูกจริงใน runtime โดยตรงตรวจไม่ได้ เพราะไม่มี instrumentation ของ `addEventListener` ตั้งแต่ก่อน script เริ่มทำงาน · จึงสรุปได้เฉพาะไม่พบการโหลดไฟล์ซ้ำ ไม่อ้างว่าได้พิสูจน์ listener ภายในทั้งหมด

## สรุป

ตรวจแล้วไม่พบปัญหา 404/5xx และไม่พบ JavaScript error · พบ WebGL performance warning 1 รายการที่ `/map/` · Ctrl+K, ตัวกรองสถานที่ และธีมข้ามหน้าผ่าน · ตัวกรอง `/eat/` และการคงค่าตะกร้าทริปตรวจยืนยันไม่ได้ตามเหตุผลที่ระบุข้างต้น
