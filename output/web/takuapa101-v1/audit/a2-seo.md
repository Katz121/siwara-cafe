# SEO audit รอบสอง

ตรวจจากไฟล์ HTML ใน `site/` จำนวน 88 หน้า และจากเว็บที่เสิร์ฟด้วย `python -m http.server 8799 --directory site` ที่ `http://127.0.0.1:8799` · ไม่ได้แก้ไฟล์เว็บไซต์ใด ๆ

## 1. sitemap.xml และ robots.txt

- **ผิด · sitemap ไม่ครบภาษาอังกฤษ** · `site/sitemap.xml:1` มี URL 44 รายการ ทั้งหมดเป็นเส้นทางภาษาไทย (เริ่ม `/` และไม่มี `/en/`) ขณะที่มี HTML จริง 88 หน้า ได้แก่ 44 หน้าไทยและ 44 หน้าอังกฤษ เช่น `site/en/index.html` และ `site/en/places/index.html` ตรวจแล้วไม่พบ URL `/en/` ใน sitemap · ผลคือหน้าภาษาอังกฤษไม่ถูกประกาศผ่าน sitemap
- **ตรวจแล้วไม่พบปัญหา** ในความสอดคล้องของ robots กับตำแหน่ง sitemap · `site/robots.txt:1-3` อนุญาต `/` และชี้ `Sitemap: https://takuapa101.com/sitemap.xml` ตรงกับไฟล์ `site/sitemap.xml:1` · เมื่อเสิร์ฟจริงทั้ง `/robots.txt` และ `/sitemap.xml` ตอบ HTTP 200
- URL ทั้ง 44 รายการใน sitemap มีไฟล์ปลายทางจริงครบจากการเทียบกับ `site/**/index.html` · `site/sitemap.xml:1`

## 2. JSON-LD

- **ตรวจแล้วไม่พบปัญหา** ด้านการ parse · JSON-LD ทั้งหมด 90 ชุดใน 88 หน้า parse ผ่าน ไม่มี JSON ที่เสียรูป และไม่พบค่า `null`, string ว่าง หรือ array ว่างใน object ที่ตรวจ · หลักฐานอยู่ใน `<script type="application/ld+json">` ของแต่ละ `site/**/index.html` (ไฟล์ HTML เป็นบรรทัดเดียว)
- **ตรวจแล้วไม่พบปัญหา** ด้านชนิดข้อมูลที่ใช้กับเนื้อหา · พบ `TouristAttraction` ในหน้าสถานที่ 40 หน้า, `Event` ในหน้าประเพณี 14 หน้า, `FAQPage` ในหน้าสถานที่ 40 หน้า, รวมถึง `BreadcrumbList`, `ItemList` และ `WebSite` ในหน้าที่เป็นดัชนี/หน้าแรก · ตัวอย่าง `site/places/wat-sena/index.html:1` และ `site/traditions/vegetarian/index.html:1`

## 3. Open Graph และ Twitter card

- **ควรแก้ · Twitter card ไม่ครบทุกหน้า** · จากการตรวจ meta tag ทั้ง 88 หน้า พบทุกหน้ามี `twitter:card` และ `twitter:image` แต่ไม่มี `twitter:title` และ `twitter:description` เลย เช่น `site/index.html:1` และ `site/en/index.html:1` · การแชร์ยังมี card ได้ แต่ title/description ไม่ได้กำหนดตรงใน Twitter metadata
- **ตรวจแล้วไม่พบปัญหา** ด้านความครบของ OG หลัก · ทุกหน้ามี `og:title`, `og:description`, `og:url`, `og:type` และ `og:image` · ตัวอย่าง `site/index.html:1`
- **ตรวจแล้วไม่พบปัญหา** ด้านไฟล์ภาพ `og:image` · URL ภาพ OG ที่ตรวจทุกหน้าชี้ไปยังไฟล์ที่มีจริงใต้ `site/assets/og/` และมี `default.png` สำหรับหน้าที่ไม่มีภาพเฉพาะ · ตัวอย่างการอ้างอิง `site/index.html:1` และไฟล์จริง `site/assets/og/default.png`
- ตรวจขนาดภาพ OG จากไฟล์จริงแล้ว ไม่พบไฟล์หายหรือขนาดเป็นศูนย์ · ยังไม่ได้ยืนยันการแสดงผลจริงบนแพลตฟอร์มโซเชียล เพราะไม่มีการยิง preview debugger ของแต่ละแพลตฟอร์ม

## 4. title และ description

- **ควรแก้ · title ยาวเกิน 60 ตัวอักษร 2 หน้า** · 62 ตัวอักษรที่ `site/index.html:1` และ `site/en/stories/index.html:1`
- **ควรแก้ · description ยาวเกิน 160 ตัวอักษร 2 หน้า** · 165 ตัวอักษรที่ `site/en/traditions/index.html:1` และ 164 ตัวอักษรที่ `site/en/routes/index.html:1`
- **ตรวจแล้วไม่พบปัญหา** เรื่อง title/description ซ้ำ · เปรียบเทียบค่าของทั้ง 88 หน้าแล้วไม่พบ title ซ้ำหรือ description ซ้ำ

## 5. ลิงก์ภายในไปยัง siwaracafe.com

- ตรวจพบ 110 เส้นจาก 88 หน้า โดยอยู่ใน `site/**/index.html` · มี anchor text 20 แบบ และมีทั้งไทย/อังกฤษ เช่น footer ซ้ำ `จัดทำโดยบ้านศิวรา ตะกั่วป่า` 44 ครั้ง และ `Created by Baan Siwara, Takua Pa` 44 ครั้ง
- **ข้อสังเกต** · รูปแบบโดยรวมดูเป็นลิงก์เครดิตผู้จัดทำที่เป็นธรรมชาติ ไม่ใช่การยัด backlink แบบใช้คีย์เวิร์ดเชิงพาณิชย์ซ้ำ ๆ · อย่างไรก็ดี การวางลิงก์เครดิตแบบ sitewide ทำให้เกิด 88 เส้นจาก footer และอีก 22 เส้นจากเนื้อหา/ส่วนอื่น จึงควรคงไว้เฉพาะถ้าตั้งใจให้เป็นเครดิตจริง
- ตรวจปลายทางว่าเป็นโดเมน `siwaracafe.com` ตามโจทย์แล้ว แต่ไม่ได้เปิดเว็บภายนอกเพื่อตรวจ HTTP ของปลายทาง · ข้อนี้จึง **ตรวจไม่ได้** ในส่วนสถานะลิงก์ปลายทาง เพราะงานนี้เสิร์ฟเฉพาะโฟลเดอร์ local

## 6. คีย์เวิร์ด ตะกั่วป่า / takuapa / Takua Pa

- คำว่า `ตะกั่วป่า` ปรากฏในเนื้อหาไทยตามบริบทสถานที่ ชื่อหน้า และคำอธิบาย · ไม่พบรูปแบบที่เป็นคำซ้ำโดด ๆ ใน title/description และไม่พบ title/description ซ้ำกันจากข้อ 4
- `takuapa` พบ 65 ครั้งใน 27 หน้า และ `Takua Pa` พบ 1,068 ครั้งใน 88 หน้า จากการนับข้อความที่แสดงผลจริง · การกระจายของ `Takua Pa` อยู่ในหน้าอังกฤษทุกหน้าและสอดคล้องกับชื่อสถานที่/เนื้อหา จึง **ตรวจแล้วไม่พบหลักฐานชัดเจนว่าถี่ยัดคำ**
- **ข้อสังเกต** · ภาษาอังกฤษมีความถี่ของ `Takua Pa` สูงกว่าคำค้นอังกฤษอีกสองรูปแบบ เพราะใช้เป็นชื่อเมืองในหัวข้อ ชื่อสถานที่ และข้อความนำทางจำนวนมาก · จากหลักฐานไฟล์อย่างเดียวเป็นการใช้งานตามบริบท ไม่ใช่ปัญหาที่ควรรายงานเป็น `ผิด`

## สรุป

รายการที่ควรแก้จริงมี 3 กลุ่ม · เพิ่มหน้า `/en/` ลง sitemap · เพิ่ม `twitter:title`/`twitter:description` ให้ครบ 88 หน้า · ย่อ title/description ที่เกินเกณฑ์รวม 4 ค่า · JSON-LD, OG image, ความซ้ำของ metadata และลักษณะ anchor backlink ตรวจแล้วไม่พบปัญหาตามขอบเขตที่ตรวจได้
