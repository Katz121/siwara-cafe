# A3 regression audit · หน้าไทย

วันที่ตรวจ: 8 กันยายน 2569  
ขอบเขต: ตรวจ regression จากรอบแก้ล่าสุดเท่านั้น; ไม่แก้ไฟล์เว็บ

## สรุป

ไม่พบปัญหา regression ที่มีหลักฐานยืนยันได้จากการตรวจที่ทำได้ในรอบนี้

## หลักฐานการตรวจ

- สั่งเสิร์ฟด้วย `python -m http.server 8798 --directory site`
- ตรวจหน้าไทย 12 หน้า: `/`, `/about/`, `/eat/`, `/leaflet/`, `/map/`, `/news/`, `/places/`, `/rest/`, `/routes/`, `/stories/`, `/traditions/`, `/trip/` — ทุกหน้าตอบ HTTP `200`
- ตรวจ `href`/`src` แบบ local จาก HTML ทั้ง 12 หน้า — ไม่พบ target ไฟล์ที่หายไป ลิงก์ `/routes/#route-1` ถึง `#route-4` เป็น fragment ภายในหน้าที่มีอยู่ จึงไม่ใช่ broken file link
- ตรวจทะเบียนข้อมูล: `data/places-enriched.json` 27 รายการ, `data/guide-picks.json` 13 รายการ, `data/shops-extra.json` 49 รายการ ตรงกับจำนวนที่ระบุไว้ใน SPEC
- ตรวจวงเล็บในข้อความที่ดึงจาก HTML ของทั้ง 12 หน้า — จำนวน `(` และ `)` สมดุลทุกหน้า
- ค้นอักขระ dash ใน HTML: ไม่พบ em dash ที่หลงเหลือในข้อความที่ตรวจ; dash ที่พบในบางหน้าเป็นคู่กับ en dash ในข้อมูล/สคริปต์ที่ฝังอยู่ จึงไม่มีหลักฐานว่าการแปลงทำให้เครื่องหมายค้างหรือข้อความตัด
- ค้นคำว่า `ถึง` ใน HTML ทั้ง 12 หน้า — ไม่พบการใช้คำนี้เป็นตัวคั่นชื่อแหล่งอ้างอิง และไม่พบข้อความที่ยืนยันได้ว่าเพี้ยนจากการแทน dash
- ส่วนที่มาในหน้าเว็บยังคงมีข้อความบอกแหล่งที่มาและลิงก์ต้นทางไปยังเอกสารเทศบาล (`travel-preview.pdf`) พร้อมคำเตือนข้อมูลที่ยังไม่ได้ยืนยัน จึงยังอ่านรู้เรื่องและระบุที่มาได้
- ตรวจบทความ 5 บทใน `site/stories/*/index.html` แบบ static: พบโครงสร้างย่อหน้าและไม่พบหลักฐานข้อความซ้ำติดกัน/วงเล็บค้างจากการแยกย่อหน้า

## สิ่งที่ตรวจไม่ได้

สภาพแวดล้อมนี้ไม่มี browser/Playwright ที่เชื่อมต่อได้ จึงไม่สามารถเก็บหลักฐาน console error, network 4xx/5xx จาก runtime หรือวัด `scrollWidth` เทียบ viewport 390/1440 ด้วย Playwright ได้ รายงานนี้ไม่อ้างผลในสามรายการดังกล่าวว่า “ผ่าน”

สคริปต์ `validate_redesign.py`/`validate_site.py` รันไม่ผ่านเพราะ assertion เดิมบังคับจำนวนไฟล์ `40` แต่ build ปัจจุบันมีจำนวนหน้าเปลี่ยนไป; ไม่ใช้ผลนี้เป็น defect ของเว็บ เพราะเป็นตัวตรวจที่ไม่สอดคล้องกับขอบเขต build รอบนี้
