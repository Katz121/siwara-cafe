# A3 · ตรวจ regression ของภาพและ asset หลังบีบขนาด

ตรวจเมื่อ 2026-09-08 · เสิร์ฟด้วย `python -m http.server 8798 --directory site` ที่ `http://127.0.0.1:8798`

## สรุป

ตรวจแล้วไม่พบปัญหาใหม่ในขอบเขตนี้

## 1 · `src` ใน HTML

- ตรวจ HTML ทั้งหมด 88 ไฟล์ และตรวจทุกค่า `src` ที่เป็น path ภายใน site
- ไม่พบ path ที่ชี้ไปยังไฟล์ไม่มีอยู่จริง
- รายการที่หาย: ไม่มี

## 2 · `og:image`

- พบ `og:image` 88 จุด จาก HTML 88 หน้า
- มี URL การ์ดไม่ซ้ำ 28 ใบ
- ทุก URL ชี้ไฟล์ที่มีอยู่จริง
- Pillow เปิดอ่าน PNG ทั้ง 28 ใบได้ และทุกใบมีขนาด `1200 × 630 px`
- รายการผิดปกติ: ไม่มี

หลักฐานจากการตรวจไฟล์: `site/assets/og/*.png` จำนวน 28 ไฟล์ · ขนาดของทุกไฟล์ `(1200, 630)` และโหมด `RGB`

## 3 · ตรวจการ์ด OG ทั้ง 28 ใบด้วย Pillow

Pillow เปิดและตรวจพิกเซลของการ์ดครบทั้ง 28 ใบ

- ไม่พบข้อความหาย: ทุกใบมีพิกเซลตัวอักษรในพื้นที่หัวเรื่องและ footer
- ไม่พบตัวอักษรล้นขอบ: bounding box ของหัวเรื่องที่ตรวจได้อยู่ในช่วง `x=45..571`, `y=143..339`; พื้นที่ข้อความเริ่มห่างขอบซ้ายอย่างน้อย 45 px และไม่ชนขอบขวา
- footer พบครบทุกใบ โดย bounding box อยู่ที่ประมาณ `x=52..270`, `y=560..594`
- รายการที่มีปัญหา: ไม่มี

## 4 · ฟอนต์ WOFF2

พบและตรวจครบ 3 ไฟล์ที่ CSS อ้างถึง:

- `site/assets/CormorantGaramond.woff2` · 37,792 bytes · HTTP 200
- `site/assets/IBMPlexSansThaiLooped-Regular.woff2` · 28,808 bytes · HTTP 200
- `site/assets/NotoSerifThai.woff2` · 123,888 bytes · HTTP 200

ทั้ง `assets/design.css` และ `assets/site.css` มีการอ้างถึงฟอนต์ครบ 3 ไฟล์ · ไม่พบฟอนต์ที่อ้างถึงแล้วหาย

## 5 · ไฟล์ที่ไม่ควร deploy

- ไม่พบไฟล์ `.ttf` ใต้ `site/`
- ไม่พบ `.ttf` ที่หลงเหลือจากการย้ายฟอนต์

## 6 · ขนาดรวมและไฟล์เกิน 300 KB

ขนาดรวม `site/`: **25,044,860 bytes** หรือประมาณ **23.88 MiB**
