สิ่งที่ต้องทำ
1. เขียนสคริปต์ `optimize_assets.py` ที่รันซ้ำได้ (idempotent) ใช้ Pillow
2. รูป guide/*.jpg · ย่อด้านยาวสุดไม่เกิน 1600px, บันทึกเป็น WebP คุณภาพ 82
   แล้วอัปเดตทุกที่ในโค้ดที่อ้าง .jpg เหล่านี้ให้ชี้ .webp (ดู design.py, build_site.py, data/guide-picks.json)
   **ต้องไม่มีรูปไหนหายจากหน้าเว็บ** เช็กด้วยการ build แล้ว grep ว่า src ทุกเส้นมีไฟล์จริง
3. og/*.png · แปลงเป็น WebP ไม่ได้ (Facebook รองรับไม่ดี) ให้บีบ PNG แทน
   ย่อเป็น 1200x630 พอดี แล้วลด palette ถ้าทำได้โดยไม่เสียคุณภาพตัวอักษร
4. municipal-map.png · เป็นแผนที่ที่ต้องซูมอ่านได้ ห้ามทำให้อ่านไม่ออก
   ให้ลองบีบแบบ lossless ก่อน ถ้าลดได้ไม่ถึง 30% ให้ทำเป็น WebP คุณภาพ 90 คู่กัน
   แล้วใช้ <picture> ให้เบราว์เซอร์เลือก โดยยัง fallback เป็น PNG เดิม
5. PDF แผ่นพับ 7.7MB · อย่าลบ แต่ให้บอกขนาดไฟล์ไว้ข้างลิงก์ดาวน์โหลดบนหน้าเว็บ
   เช่น "ดาวน์โหลดแผ่นพับ PDF · 7.7 MB" เพื่อให้คนตัดสินใจก่อนกด
6. รูปทุกใบใน HTML ต้องมี width และ height กำกับ (ตอนนี้ขาด 134 จุด) กันหน้าเด้งตอนโหลด
   ให้อ่านขนาดจริงจากไฟล์แล้วเติมให้ครบ
7. รัน `python build_site.py` และ `python build_en.py` ต้องผ่าน · 44 + 44 หน้า
8. เช็กท้ายงาน: ไม่มี src ที่ชี้ไฟล์ไม่มีจริง · ขนาดรวมของ site/assets/ ลดลงเท่าไร
9. เขียนสรุปที่ `audit/fix-images.md` บอกขนาดก่อน/หลังรายไฟล์

ห้ามเปลี่ยนดีไซน์ ข้อความ หรือ layout · งานนี้คือลดน้ำหนักอย่างเดียว
